# Mechatronics Quiz App

## What it does
The Mechatronics Quiz App is a simple Python programme that tests a student's knowledge of mechatronics and basic engineering. It asks 10 multiple-choice questions, checks each answer, keeps the score, and displays the final percentage and grade.

## How to run it
1. Install Python 3 or open a Python app such as Pydroid 3 on Android.
2. Save the programme as `mechatronics_quiz.py`.
3. Run it with:

```bash
python mechatronics_quiz.py
```

## My own twist
I added instant feedback with a short explanation after every wrong answer. This helps the student understand the correct answer instead of only seeing the final score.
